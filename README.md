# Interactive Web Calculator

https://priyarajawat188.github.io/Calculator/LiveDemo A clean, responsive, and interactive Web Calculator built using fundamental web technologies: **HTML5, CSS3, and JavaScript**. 

This application performs basic arithmetic operations with a modern UI featuring smooth button hover effects and custom styling.


## Features

* **Basic Arithmetic Operations**: Addition (`+`), Subtraction (`-`), Multiplication (`*`), Division (`/`), and Percentage (`%`).
* **Clear (`AC`) & Delete (`DEL`)**: Quickly clear the entire input display or delete the last entered digit.
* **Double Zero Button (`00`)**: Easily enter multiple zeros in one click.
* **Neumorphic / Modern UI**: Stylish design using CSS gradients, custom shadows, and dynamic hover effects.
* **Pure JavaScript**: Built with vanilla JavaScript using event listeners and DOM manipulation without any external libraries.

---

## Tech Stack

* **HTML5**: Markup structure for the calculator buttons and display.
* **CSS3**: Custom layout, gradients, box-shadows, and responsive styling.
* **JavaScript (ES6)**: Functional logic for mathematical operations and event listeners.
